Existencias por sucursal

02

Consulta las existencias actuales y el mínimo configurado.

SELECT s.nombre AS sucursal,
       p.sku,
       p.nombre AS producto,
       i.stock,
       i.stock_minimo
FROM inventario i
JOIN producto p ON p.id_producto = i.id_producto
JOIN sucursal s ON s.id_sucursal = i.id_sucursal
ORDER BY s.nombre, p.sku;

Ventas recientes

03

Revisa los últimos folios, sucursales e importes registrados.

SELECT v.folio,
       s.nombre AS sucursal,
       v.fecha_venta,
       v.total
FROM venta v
JOIN sucursal s ON s.id_sucursal = v.id_sucursal
ORDER BY v.fecha_venta DESC;
